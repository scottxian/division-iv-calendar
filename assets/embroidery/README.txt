Embroidery shop instructions
- SVG is vector artwork, NOT a machine embroidery file. Convert/digitize to the DST, PES, EXP, etc. file appropriate to your machine. No claim of completed machine-ready digitization.
- No font dependencies, gradients, shading, JPEGs, embedded bitmap images, or transparency inside the emblem. Background beyond the circle is transparent.
- Recommend navy twill rather than dense navy fill for a patch if possible.
- Use proper underlay, pull compensation, stitch angles, corner handling, and test sew-out on the actual backing/fabric. Design thickness and thread sequencing are the digitizer's responsibility.
- If lettering is too small at the selected physical size, use the polo/hat version without directions.
- Physical stitch proof should be approved before production.

This package is based on the corrected evenly colored navy Division IV brand and visually matches its major symbols, but is a purposely simplified stitch-friendly interpretation.
