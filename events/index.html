Manage the menu links shown across the public Division IV pages. These links open public pages or the existing Inspector Desk sign-in; editing a link does not grant anyone additional access.

How do I edit menu links? Show instructions and examples

Dropdown: Choose which top menu contains this link: Division, Lodges, Calendar, or Inspectors. Home is a separate permanent link.

Menu text: Enter what visitors should read, such as View Calendar or Lodge Directory.

Destination: Pick a common website page or a saved website link. Choose Custom link only when you need another page or a secure https:// URL. Saved links automatically follow changes you make in the website settings above.

Order: Use the arrows to move a link higher or lower. Remove only deletes a link from the dropdown after you save; it does not delete the destination page. Use Preview to test where it opens.

Save: Click Save Website Settings below, then reload a website page to see the updated menu. Restore saved links undoes unsaved menu edits.
